# Nepali Patro – public holiday list

`holidays.json` is read by the Nepali Patro app on each phone to pick up
government holidays, including ones declared at short notice.

- `base.json` – the Ministry of Home Affairs list (edit this when a new year's list is published).
- A GitHub robot checks the calendar every 3 hours and adds any newly declared holiday.

This repository contains no personal data.
